# 03. Память и контекст

Что агент **помнит** между шагами и сессиями и как управляет содержимым контекстного окна. Эталонная рамка - **CoALA** (Cognitive Architectures for Language Agents): рабочая (working) память для текущего цикла + три долговременных типа.

```
                 ┌── эпизодическая (прошлый опыт)
рабочая память ──┼── семантическая (факты о мире)
  (текущий цикл) └── процедурная (навыки/код/процедуры) ← запись рискованнее всего
```

## Паттерны и концепции группы

| Паттерн                 | `id` (папка)          | Суть в одну строку                                                    | Статус      | Карточка |
|-------------------------|-----------------------|-----------------------------------------------------------------------|-------------|:--------:|
| Типы памяти (CoALA)     | `memory-types`        | Working + эпизодическая/семантическая/процедурная                     | established |    ⏳     |
| MemGPT / Letta          | `memgpt`              | ОС-подобная иерархия памяти: пейджинг контекст ↔ хранилище            | emerging    |    ⏳     |
| Generative Agents       | `generative-agents`   | Memory stream + retrieval (recency/importance/relevance) + reflection | emerging    |    ⏳     |
| Skill library (Voyager) | `skill-library`       | Агент пишет код-навык и переиспользует его                            | emerging    |    ⏳     |
| Context engineering     | `context-engineering` | Суммаризация, свежий контекст субагентов, «playbook, не транскрипт»   | emerging    |    ⏳     |

## Порядок чтения

Начать с **memory-types** (CoALA) - это словарь для всей группы. Затем **context-engineering** как самая практичная дисциплина сегодня. **MemGPT/Letta** и **Generative Agents** - конкретные архитектуры долговременной памяти. **Skill library** - про процедурную память (пересекается с группой 06).

## Ключевые уроки

- **Отделяйте хранилище от политики извлечения.** Плохая retrieval-политика → «отравление памяти», ложные факты. Инструменты: Mem0, Zep, Graphiti.
- **Reflection не опционален** для долгих горизонтов: абляция в Generative Agents показала, что удаление reflection обрушивает связное многодневное планирование.
- **Храните playbook, а не транскрипт.** Суммаризируйте завершенные фазы во внешнюю память; спавните свежих субагентов с чистым контекстом при приближении к лимиту.
- **Процедурная память опаснее** эпизодической/семантической: ошибочный записанный «навык» будет воспроизводиться.
