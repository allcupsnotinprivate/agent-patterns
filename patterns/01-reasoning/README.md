# 01. Рассуждение и планирование

Как **одиночный** агент думает. Паттерны этой группы образуют лестницу по «форме поиска» (ось C таксономии): от линейной цепочки к дереву и графу. Чем правее по лестнице - тем выше точность на трудных задачах и тем дороже вычисления.

```
цепочка → выборка+голосование → цикл → отложенная интеграция → параллельный DAG → дерево → граф → поиск по дереву → самоисправление
  CoT        Self-Consistency    ReAct       ReWOO           LLMCompiler   ToT   GoT      LATS         Reflexion/Self-Refine/CRITIC
```

## Паттерны группы

| Паттерн           | `id` (папка)       | Суть в одну строку                                                           | Статус       | Карточка |
|-------------------|--------------------|------------------------------------------------------------------------------|--------------|:--------:|
| Chain-of-Thought  | [`cot`](cot/)      | Пошаговое рассуждение в тексте перед ответом                                 | established  |  [✅](cot/)  |
| Self-Consistency  | [`self-consistency`](self-consistency/) | Несколько путей рассуждения → берем самый частый ответ                       | established  |  [✅](self-consistency/)  |
| ReAct             | [`react`](react/)  | Цикл Thought → Action → Observation; дефолт для tool-using агентов           | established  |  [✅](react/)  |
| ReWOO             | `rewoo`            | План с плейсхолдерами + пакетное исполнение; 2 вызова вместо N               | established  |    ⏳     |
| Plan-and-Execute  | `plan-and-execute` | План всех шагов заранее, затем исполнение (часто дешевой моделью)            | established  |    ⏳     |
| LLMCompiler       | `llm-compiler`     | Planner стримит DAG задач, исполнение параллельно по готовности зависимостей | emerging     |    ⏳     |
| Tree of Thoughts  | `tot`              | Ветвление мыслей, оценка узлов, поиск BFS/DFS с бэктрекингом                 | established  |    ⏳     |
| Graph of Thoughts | `got`              | Мысли как граф: агрегирование и переиспользование ветвей                     | experimental |    ⏳     |
| LATS              | `lats`             | MCTS + value-функции + рефлексия + обратная связь среды                      | experimental |    ⏳     |
| Reflexion         | `reflexion`        | Вербальное RL: саморефлексия в эпизодическую память между попытками          | established  |    ⏳     |
| Self-Refine       | `self-refine`      | Одна модель в трех ролях: генератор → критик → редактор                      | established  |    ⏳     |
| CRITIC            | `critic`           | verify → critique → correct с опорой на внешние инструменты                  | established  |    ⏳     |

## Порядок чтения

Сверху вниз по таблице: это и есть лестница усложнения. Практический дефолт для агента с инструментами - **ReAct**; при дорогих инструментах - **ReWOO / Plan-and-Execute**; деревья (**ToT/LATS**) - только когда есть проверяемые промежуточные состояния и оправдана ×N-стоимость.

## Важная оговорка

Reasoning-модели (o-series, DeepSeek-R1, extended thinking) частично **интернализуют** эти паттерны. Для них не стоит добавлять лишний CoT-скаффолд - это может ухудшить результат. Подробнее - в [`Taxonomy`](../../taxonomy.md#ключевой-сдвиг-20252026).

Про надежность самоисправления: чистая «intrinsic self-correction» без внешнего сигнала ненадежна - предпочитайте **CRITIC** и evaluator-optimizer с независимым критиком.
