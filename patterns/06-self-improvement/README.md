# 06. Самоэволюция

Как система **улучшает сама себя**. Раскладка по оси B - *что* именно эволюционирует: промпт → память/навыки → инструменты → топология → сам код агента → веса.

**Главное предупреждение группы.** Без замороженного, недоступного агенту для правки бенчмарка «самоулучшение» неотличимо от дрейфа: собственная метрика оптимизатора не является доказательством. Отсюда риск «objective hacking».

## Паттерны группы

| Паттерн               | `id` (папка)           | Что эволюционирует                                                | Статус       | Карточка |
|-----------------------|------------------------|-------------------------------------------------------------------|--------------|:--------:|
| DSPy                  | `dspy`                 | Промпты/пайплайн (декларативные signatures + оптимизаторы)        | emerging     |    ⏳     |
| TextGrad              | `textgrad`             | Промпты через «текстовые градиенты» (NL-критика назад по системе) | emerging     |    ⏳     |
| GEPA                  | `gepa`                 | Промпты (рефлективная эволюция) - готов к продакшену              | emerging     |    ⏳     |
| Voyager skill library | `skill-library`        | Навыки (исполняемый код) - см. также группу 03                    | emerging     |    ⏳     |
| GPTSwarm              | `gptswarm`             | Топология (граф агентов, оптимизация ребер)                       | experimental |    ⏳     |
| AgentSquare           | `agentsquare`          | Модульное пространство + байесовская оптимизация                  | experimental |    ⏳     |
| ADAS                  | `adas`                 | Сам код агента (meta-agent программирует новых агентов)           | experimental |    ⏳     |
| AFlow                 | `aflow`                | Workflow через MCTS с переиспользуемыми операторами               | experimental |    ⏳     |
| Gödel Agent           | `godel-agent`          | Собственная логика (рекурсивное переписывание)                    | experimental |    ⏳     |
| Darwin Gödel Machine  | `darwin-godel-machine` | Свой код + архив, эмпирическая валидация на бенчмарках            | experimental |    ⏳     |
| Agentic RL            | `agentic-rl`           | Веса (RL по темпорально-протяженному POMDP)                       | emerging     |    ⏳     |

## Порядок чтения

По возрастанию радикальности того, что меняется: **промпты** (DSPy → TextGrad → GEPA) → **навыки** (Voyager) → **топология** (GPTSwarm, AgentSquare) → **код** (ADAS → AFlow → Gödel Agent → Darwin Gödel Machine) → **веса** (agentic RL).

## Практический ориентир

- **Готово к продакшену:** DSPy, GEPA - для оптимизации промптов.
- **Исследовательское, только с замороженным бенчмарком:** ADAS, AFlow, Gödel Agent, DGM. Агент не должен иметь возможности править сам бенчмарк.
- Новее фронтир (см. `papers/`): **PACE** - anytime-valid тесты принятия самомодификации, закрывающие дыру «objective hacking».
