# Глоссарий

Термины, которые встречаются в карточках и заметках. Отсортированы по алфавиту (латиница, затем кириллица). Ссылки в скобках `[→ id]` ведут на будущие карточки паттернов.

## A-Z

**ACI (Agent-Computer Interface)** - интерфейс между агентом и инструментами: описания инструментов, форматы аргументов, примеры, poka-yoke-параметры. Anthropic советует вкладываться в ACI столько же, сколько в UX для людей: плохой ACI ломает агента так же, как плохой UI ломает человека.

**Agent** - система, где LLM динамически управляет своим процессом и использованием инструментов (в отличие от workflow). См. главную развилку в [`Taxonomy`](taxonomy.md#главная-развилка-workflow-vs-agent).

**Agentic RAG** - RAG, в котором извлечение управляется решениями агента: когда искать, что переспросить, доверять ли документу. Примеры: Self-RAG (reflection-токены), CRAG (оценка релевантности + веб-поиск как fallback).

**A2A (Agent2Agent)** - горизонтальный протокол «агент ↔ агент» (Google, апрель 2025; передан в Linux Foundation). HTTP + SSE + JSON-RPC 2.0, Agent Cards, жизненный цикл задачи. Дополняет MCP, а не заменяет.

**Blackboard** - топология, где агенты читают и пишут в общую «доску состояния» вместо прямой адресной коммуникации.

**CoALA (Cognitive Architectures for Language Agents)** - эталонная рамка памяти агента: рабочая (working) память + три долговременных - эпизодическая, семантическая, процедурная. Запись в процедурную рискованнее, чем в эпизодическую/семантическую.

**Context engineering** - дисциплина управления содержимым контекстного окна: что положить, что суммаризировать, что вынести во внешнюю память, когда спавнить свежий контекст. «Храните playbook, а не транскрипт.»

**Dual-LLM** - паттерн безопасности: привилегированный планировщик не читает недоверенный текст, а quarantined-worker читает недоверенный текст, но лишен инструментов. Реализация с провенанс-трекингом - CaMeL. Автор идеи - Simon Willison (2023).

**Guardrails** - проверки на входе/выходе агента (часто параллельным LLM-вызовом), отсекающие небезопасные или нерелевантные запросы и действия.

**Handoff** - передача полного контроля от одного агента другому без центрального оркестратора (peer-to-peer). Примитив OpenAI Agents SDK; идет от эксперимента Swarm.

**HITL (Human-in-the-loop)** - включение человека в петлю на чувствительных/необратимых действиях (подтверждение перед выполнением).

**Lethal trifecta** (Simon Willison) - опасная комбинация трех доступов у одного агента: приватные данные + недоверенный контент + внешняя коммуникация. Вместе они превращают prompt injection в утечку.

**LLM-as-judge** - использование LLM для оценки вывода (другого LLM или своего). Надежнее, когда критик **независим** от генератора (см. evaluator-optimizer), чем при «intrinsic self-correction».

**MCP (Model Context Protocol)** - вертикальный протокол «агент ↔ инструменты/данные» (Anthropic, ноябрь 2024). Стандартизует подключение источников контекста и инструментов к моделям.

**pass@k / pass^k** - метрики. `pass@k`: задача решена хотя бы в одной из k попыток (способность). `pass^k`: задача решена во **всех** k попытках (надежность). Для агентов важна вторая.

**POMDP** - частично наблюдаемый марковский процесс принятия решений; формализм, к которому agentic RL сводит темпорально-протяженное поведение агента (в отличие от одношагового MDP классического LLM-RL).

**Reasoning-модели (test-time compute)** - модели, тратящие вычисления на внутренние reasoning-токены перед ответом (o1/o3, DeepSeek-R1, Claude extended thinking). Интернализуют планирование и рефлексию, частично заменяя внешние скаффолды.

**Scaffold (скаффолд)** - внешняя обвязка вокруг вызовов модели: управляющий цикл, определения инструментов, стратегия работы с контекстом, состояние. Надежность агента - во многом свойство скаффолда, а не только модели.

**Self-correction (intrinsic)** - попытка модели исправить себя без внешнего сигнала. Ненадежна (Huang et al., ICLR 2024): без внешней проверки (инструмент, независимый критик) улучшение не гарантировано.

**SOP (Standard Operating Procedure)** - жесткая последовательность ролевых шагов/handoff-ов (PM → архитектор → разработчик → QA). Основа MetaGPT/ChatDev: «Code = SOP(Team)».

**Supervisor / subagents** - иерархическая топология: ведущий агент планирует и делегирует субагентам, работающим в изолированных контекстах и возвращающим сжатые сводки. Дефолтная точка входа в мультиагентность.

**Test-time compute** - см. Reasoning-модели.

**Tool / function calling** - базовый механизм действия: модель возвращает структурированный вызов инструмента, рантайм его исполняет и возвращает результат в контекст.

**Workflow** - система, где LLM и инструменты оркестрируются через заранее заданные пути в коде. См. главную развилку в [`Taxonomy`](taxonomy.md#главная-развилка-workflow-vs-agent).

## Кириллица

**Скаффолд** - см. Scaffold.

**Субагент** - агент, работающий под управлением супервизора в изолированном контексте. См. Supervisor / subagents.
